# 投递线

负责岗位核验、材料对应、申请回执和反馈，不维护第二份个人履历。

## 工作入口

- 条件来自 [个人档案]({{PROFILE}})，方向来自行业线。
- 使用 [检索范围]({{SCOPE}}) 和 [执行策略]({{POLICY}})，步骤见 [执行手册]({{METHODS}}/RUNBOOK.md)。
- 从通用仓库运行 `python -X utf8 scripts/chain.py status` 查看本地台账，SQLite 位于 [运行数据]({{DATA}})/ledger.sqlite3。

## 当前推进

尚无真实申请。每个岗位关联 APP-ID、官方来源与核对日期、资格结论、简历版本、回执、反馈类型及下一动作。未知结果先回查，避免重复投递。

初筛即可准备材料和启动用户自己的投递，不等学习完成。资格拒绝、无回复、技术面缺口分别处理。默认不代投、不联系他人。飞书按授权放进度看板、跟进和阶段总结，本地保留必要去重与恢复状态。
