# 行业研究方法

本目录是所有使用者共用的行业研究能力，纳入 Git。研究路径、渠道、报告读法、景气信号、护城河判据及可复用的行业认识在此维护，不随个人建档重新复制。个人是否愿意进入、城市和回报要求写个人档案；针对个人的推荐及改判条件写当前状态。

先用本页判断需求和产业位置，再用 [企业背调方法论](企业背调方法论.md) 核企业与岗位，用 [岗位筛选规则](岗位筛选规则.md) 比较个人准入和投入。行业值得研究、企业经营好、岗位值得加入是三个结论，分别取证。

## 从问题出发查资料

先界定细分产品或服务、付款人、地域和观察期间，画出“需求方 → 采购/渠道 → 交付方 → 关键供应商”的关系。不要直接以“AI”“新能源”“国央企”这种大标签判断好坏。每次查询明确要验证哪条假说，以及什么结果会推翻它。

| 要回答的问题 | 优先渠道与材料 | 重点读取 | 不能直接推导什么 |
| --- | --- | --- | --- |
| 需求、产量与经营是否变化 | [国家统计局](https://www.stats.gov.cn/)及地方统计部门的月度发布、统计公报、年鉴 | 指标定义、行业口径、量价、同期和累计、修订及基数 | 总行业增长不能证明每个细分市场或岗位增长 |
| 政策怎样产生实际需求 | [中国政府网政策库](https://www.gov.cn/zhengce/)、发改及行业主管部门原文、地方实施文件 | 发文主体、适用范围、生效期限、预算来源、实施/验收/退出条件 | 规划目标、试点名单不等于订单、落地或收益 |
| 产业是否真实运行 | [工信部](https://www.miit.gov.cn/)及相关行业主管部门运行报告；能源问题查[国家能源局](https://www.nea.gov.cn/)的统计、规则、项目和行业报告 | 实际生产、交付、运行与利用，规模和单位收益分别看 | 项目核准、规划产能与实际投产不能混用 |
| 谁在付钱、买什么 | [中国政府采购网](https://www.ccgp.gov.cn/)、对应公共资源交易平台、采购方官网 | 采购意向、招标、成交、合同、验收分别对应什么阶段；预算、对象、供应商和续购 | 同一项目的多次公告不算多笔需求，中标不等于收入或回款 |
| 企业能否留住收益 | 交易所、[巨潮资讯网](https://www.cninfo.com.cn/)及企业投资者关系页中的定期报告、招股书、问询回复 | 分部业务、客户集中度、毛利、经营现金、应收/存货、合同负债及风险说明 | 集团盈利、签约额或管理层预测不能直接证明目标业务质量 |
| 是否存在不可轻易替代的权利 | 立法及监管机关、授权机关、许可/认证名录和特许经营文件 | 权利持有人、地域/期限、业务范围、续期及替代机构 | 国资背景、集团关联、参与标准制定不自动等于独占权 |
| 增长是否转化为就业机会 | 企业官方招聘、具体团队原 JD、后续招聘反馈 | 多个独立雇主、岗位职责、准入、名额状态、实际工作地 | 页面数量、重复发布、常年人才库不等于新增 HC |
| 实际工作体验如何 | 对应团队面经、公开从业者访谈和用户/客户反馈 | 具体事件、岗位/团队、发生时间、独立来源及利益关系 | 单个匿名故事不能代表企业全貌，也不能改写官方资格条件 |

行业协会、券商及咨询报告用于补产业链和提出假说，优先回查其原始数据。核发布者、赞助/销售利益、统计范围、样本、估算方法和原始出处；多篇报告引用同一数据源只算一份证据。公开可读不代表可以整份转载，方法中保留必要结论和来源即可。

渠道入口核对：2026-11-25。统计局、工信部、国家能源局和巨潮首页可读取；政府网政策库、政府采购网本轮读取受限，具体文件仍需另核。入口地址不证明某份政策仍有效，也不代表已完成某个行业的研究。

## 怎样看上行、下行与分化

以下是研究判据，不是机械打分表；应按细分行业选择有意义的指标，没有通用阈值。

| 维度 | 支持改善的信号 | 提示恶化或分化的信号 | 必须排除的解释 |
| --- | --- | --- | --- |
| 终端需求 | 多个独立付款人的持续采购、使用或复购增加 | 取消/延后采购、持续缩量、客户退出 | 单一大客户、一次性补贴、试点或免费采用 |
| 量价与利润 | 销售增长能转化为有质量的毛利和利润 | 量增价跌、价格战、收入增长但盈利恶化 | 产品结构、并购并表、会计口径、汇率与低基数 |
| 现金与周转 | 同口径经营现金、收款和存货周转改善 | 利润增长但应收/库存持续积压、回款变慢 | 季节性、结算周期和业务模式的正常差异 |
| 供需与产能 | 实际使用和交付承接新增能力 | 扩产快于有效需求、闲置或产能退出 | 核准/规划替代投产，投产替代有效利用 |
| 政策与预算 | 规则落地、预算落实，并出现执行和验收 | 支持条件收紧、项目取消、付款约束或退出 | 政策表态直接当经营结果 |
| 人才与组织 | 多个雇主出现与业务交付有关的真实岗位和面试需求 | 反复冻结、撤岗、职责外包化或核心团队收缩 | 重复职位、季节招聘及单家公司调整 |

用近三个月新证据发现变化，再用适合该行业的多个可比期间解释趋势，不能用单月同比概括周期。区分领先信号（询单、预算）、实际执行（交付、使用）、结果（利润、回款）；同一条链的多个阶段不是独立证据。

行业可能出现需求上行而利润下行、总量增长而中小企业退出、集团增长而目标团队缩编。结论明确写“哪个环节、哪类企业、什么指标、什么期间改善/恶化”，保留冲突、未知和反证。政策、融资或招聘中的单个积极信号不直接升级为朝阳行业。

## 什么进入公共知识，什么留在个人工作区

公共部分持续更新：细分行业边界、产业链位置、需求/供给机制、可查来源、关键指标、证据支持的判断及失效条件。确有下一次复用价值的行业结论可以入 Git，但需有原始来源、数据期间和核对日期；不固化一份永远有效的好行业名单，不保存逐日抓取全文或一次性比较报告。

个人部分分别维护：profile 记录本人意向和限制；当前状态记录为什么此人主投、并行或暂缓某方向；岗位台账记录具体 JD、本人差距与招聘反馈。公开事实与个人适配可以引用同一方法，不在各个人目录再复制方法全文。

研究结束时回答：当前结论、关键依据、主要反证/未知、下一项最小核查。只在新事实会影响判断时继续补查；消费完的摘录提炼后清理，政策原文未核不能写成确定规则。
