# 企业背调方法论

回答三件事：业务是否值得加入，岗位是否有实际资源，本人能否获得回报。投入随招聘进展增加，初筛只核会改变决定的信息，邀约后再补团队和用工细节。

## 护城河与价值分配

| 主体与壁垒 | 需要验证 | 常见误判 |
| --- | --- | --- |
| 市场竞争优势 | 客户采购、成本/性能、切换成本、合法独有数据、服务网络、渠道及替代方案 | 技术难度高即永久领先，融资多即需求强 |
| 法定或行政独占 | 现行法规/授权文件、业务范围、地域期限、权利持有人及例外 | 仅凭国资背景或旧牌照认定独占 |
| 特许经营与通道 | 招标或授权、结算/定价通道、续期条件、竞争范围 | 区域优势当全国垄断，供应商当通道所有者 |
| 资源与数据产权 | 实际权利、合法使用范围、稀缺性及可替代性 | 有数据就有独占权，母公司资源自动属于子公司 |
| 信任与认证 | 法定职责或适用资质、市场采用、竞争机构及资格更新 | 做测试等于有认证权，参与标准起草等于控制规则 |
| 财政与组织支持 | 预算、拨付、编制/合同、持续投入和退出机制 | 国家背景保证公司永续或个人高薪 |

沿“签约主体 → 实际用工团队 → 资源/权利持有人”核查关联。强壁垒可能保护组织，却未必流向目标岗位。继续核岗位能否参与核心价值、分享回报和积累可迁移能力，不能推定 IT 一定边缘或某种身份一定稳定。

AI 评测、数据服务等新业务可用同一套问题判断，不预设有新增牌照或独占权。制度与资格是动态事实，引用当前官方文件和核对日期；没有文件就保留假说。公司自述、社区口碑、采购数据各回答不同问题，不把热议当法律口径，也不把宣传当经营实绩。

## 三层核查

1. 公司层复用 [C1–C5](岗位筛选规则.md)：生态位、客户、增长、现金、团队资源。分析终端需求及上游/客户风险，区分结构性变化与周期波动。
2. 风险层 C6：工商主体、司法与经营异常、欠薪社保、用工关系。记录事实、适用范围与整改状态，单一诉讼或负面帖子不自动等于公司不可靠。
3. 岗位层 C7：新增或替补名额、汇报线、团队规模、前任离开原因、真实 KPI、自研/交付边界、工作强度、薪酬兑现和业务收缩后的安排。

派遣/外包拆开劳动合同主体和实际客户。合规、工资与合同看劳动主体，目标业务与团队看实际用工方；按用户是否接受这类关系决定。供应商、集团子公司、正式编制不得混称。

## 证据与结论

规则以适用的官方公告、法规与招聘岗位表为准；经营看原始财务、采购、客户与交付证据；内部工作体验用一线访谈和口碑交叉，标注样本偏差。观点冲突写明，搜索摘要仅作线索。事实、推断、未知分开。

一份在用岗位记录应能回答：结论和理由、来源及核对日期、关键缺口、面试核验项、下一动作。shortlist 是可争取，clarify 是需补证，exclude 是已证实不合适，不把资料缺失写成不存在。

只保留下一步会复用的结论与必要来源，已消费的全文抓取无需永久存档。回执、合同、资格争议的唯一证据等具有实际后续用途时按私有资料保留。
