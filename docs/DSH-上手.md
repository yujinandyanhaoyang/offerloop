# 可选浏览器接入

通用首次使用见 [README](../README.md) 和 [建档与接续](建档与接续.md)，无需安装 DSH、飞书或浏览器即可建档。本页仅说明已有页面工具的依赖，文件名为兼容旧链接保留。

- 需要页面功能时准备 Node.js 22+ 和 Chrome。browser_cdp.js 使用 Node 内置 WebSocket；browser_pw.js 还需要可用的 Playwright 环境。按当前宿主允许的浏览器工具操作，不以脚本绕过宿主边界。
- Windows 用户可按需手动运行 scripts/browser_launch.cmd，启动专用 Chrome profile。登录由本人完成，不在聊天或配置中保存密码、验证码。
- 使用 `node scripts/browser_cdp.js --help` 或查看脚本入口获取命令。必须以当前完整 URL 或明确 tab ID 选目标，不向其他标签回退。
- 先观察当前页面再核实选择器。字段填入、服务器保存、真实提交及招聘方回执分开确认。上传和填写可能触发自动保存，需事先有对应操作授权。
- 页面不可读时可先走招聘官网或其他已授权公开来源。检索与材料工作不依赖某个平台持续可用。

详细执行边界与本地台账入口见 [执行手册](RUNBOOK.md)。浏览器、网络和平台兼容性取决于实际设备，不承诺固定时长或全平台自动化成功率。
