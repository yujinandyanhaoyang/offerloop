# 文档同步说明（DOCS-SYNC）

## 两套文档的关系

- **唯一来源 = `规则\`**（10 份现行规则，唯一维护来源）：职业适配工作流、公司与岗位过滤器、企业背调方法论、行业方向线、决策教练、财富材料索引、成果表达、月度OKR、两周求职准备/执行提示词。
- **`harness\docs\` 是开源去个人化副本**：把可复用的求职执行 Harness 抽成不含个人数据、绝对路径、目标公司名的公开版本。对应关系：
  - `岗位筛选规则.md` ← `规则\AI时代公司与岗位过滤器.md`（去个人化）
  - `企业背调方法论.md` ← `规则\企业背调方法论.md`（同名去个人化）
  - `能力手册.md` / `海投链路.md` / `RUNBOOK.md` / `INTERVIEWS.md` / `通用打招呼话术.md` 为 harness 专属，无 `规则\` 对应。

## 发布前必须同步

发布（开源）前，`harness\docs\` 需与 `规则\` 重新对齐；`规则\` 有更新时，先同步到 `harness\docs\` 再发布。同步只做「去个人化翻译」，不复制个人事实、台账路径、目标公司名。

## 去个人化约定

- 目标公司名 → 通用描述（如「某家具设计SaaS公司」「某科技大厂」「某外包派遣公司」）。
- 指向个人规则/台账/交接的链接 → 改为「见个人项目 规则\…」纯文本，不写绝对路径。
- 个人数据、绝对路径、公司名一律不进入开源副本。
