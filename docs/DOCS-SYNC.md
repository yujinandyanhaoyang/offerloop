# 文档归属

通用 docs 随仓库发布，维护建档、方法、命令及配置契约。个人实例维护现行判断与产物，个人选择不改成所有人的默认规则。

| 通用维护 | 实例维护 |
| --- | --- |
| 建档与接续、空模板 | 统一个人档案及 memory 的下一动作 |
| 岗位筛选、企业背调 | 行业线当前方向、准入结论与改判条件 |
| 材料与训练方法 | 内容线简历与项目证据，笔面线题源与原回答 |
| 执行手册与工具 | 投递线配置、回执、反馈与私有云端绑定 |

输入只维护一份，跨线引用。共用行为变化时更新对应方法、模板和必要验证，不追加一篇日期报告。研究摘录提炼后清理，唯一回执、去重和未完任务继续保留。发布仅包含通用文件，先在空目录验证。
