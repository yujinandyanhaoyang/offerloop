# 通用打招呼话术（一套复用）

2026-10-31。大规模招聘岗 HR 批量处理候选，不逐人深读，故**不逐岗打磨话术/简历**：只用一套通用话术 + 一套通用简历，仅在「核心/强匹配岗」才微调。`{岗位}` 是唯一变量，其余固定。

## 打招呼 / 先聊聊（BOSS、智联等）

> 您好，我对贵司「{岗位}」很感兴趣。本人{学历/背景}，{核心技能}，有{相关项目经验}，并有真实业务落地与评测证据。简历已更新，希望有机会沟通。谢谢！

## 投递说明 / 求职信（简短，附件投递用）

> 您好，投递贵司「{岗位}」。本人{学历}，{主力语言}，做过{相关项目}，掌握{关键能力}。附件为简历，期待沟通。谢谢！

## 使用规则

- **一套话术**：所有大规模招聘岗复用上方模板，只替换 `{岗位}` 与 `{你的背景/技能/项目}` 占位符。
- **一套简历**：统一用 `config/resume.pdf`（或一份通用简历），不逐岗另写版本。
- **微调例外**：仅当岗位是「核心机会、高匹配、有面试意愿信号」时，才针对 JD 补 1–2 句（如领域术语、具体项目映射）。
- 原则：HR 对批量候选不逐人深读，话术/简历的核心是「让人 3 秒看懂你匹配」，不是堆细节。
