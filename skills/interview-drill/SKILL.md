# 面试回放训练

把「每天练几道真实面试题」变成可复用的固定动作：**出题 → 脱稿作答 → 记录 → 纠偏 → 缺口跟进 → 分批归档**。所有数据在本仓库 `data/` 下，不入库。

## 铁律

1. **只出题、计时、记录、纠偏，不代答。** 使用者答不出就记「不会」，再给参考口述；不得把参考口述说成已掌握。
2. **参考答案要能说出口。** 写成 2—3 段连贯的话，不用多层嵌套（不搞「①②③ 再挂 a/b/c」）。
3. **数字要能核。** 口述里出现的数字，能在本地记录查到才引用并注明出处；查不到就不给精确值，改说「初步判断」。
4. 每题最多 1—2 个追问，达到关键判断即收束。

## 工具

```bash
python -X utf8 scripts/interview_drill.py status
python -X utf8 scripts/interview_drill.py add --json q.json     # 或 --json - 走 stdin
python -X utf8 scripts/interview_drill.py batches               # 每 5 题一批
python -X utf8 scripts/interview_drill.py mark-synced 1
```

- 台账：`data/interview-ledger.json`（唯一事实源，已 gitignore）
- 批次原文：`data/batches/batch-NN.md`
- payload 必填：`qid`/`date`/`source`/`company`/`question`/`answer_status`
- 可选：`answer_point`/`correction`/`我的原始回答`/`参考口述`/`追问与纠偏`/`gap_ids`/`ref_position`
- `answer_status`：`答出` / `部分答出` / `不会`；`我的原始回答` 记使用者原话，不要润色成范文。

## 一轮怎么走

1. **抽题**：从面经材料取真实社招题，标明公司／轮次；优先覆盖还没练过的话题。
2. **出题**：一次一题，提示落到使用者自己的项目，允许说「不会」。
3. **记录**：用脚本写入，不手搓 JSON。
4. **纠偏**：先肯定对的，再点 2—3 处必须改的，最后给参考口述。
5. **缺口**：暴露的不会项并入缺口表，**必须写具体补习动作**（读哪段、造什么最小验证），不写「去学习一下」。
6. **归档**：满 5 题或叫停时 `batches`。**同步是可选的**——需要云端看板时才同步（校验通过后 `mark-synced`）；不做同步也能完整使用，数据本来就全在本地。
7. **汇报**：本批题数、答出／部分／不会分布、缺口变化、下一步。不写流水账。

## 边界

- 不代答、不美化战绩、不把模拟成绩说成真实面试结果。
- 复验一律用**异题／异例**，不重复原题；通过才把缺口标「已复验」。
- 不写业务数据、不发布、不通知。
